PdfCraft Mobile for Android
===========================

Version: 0.8.0-touch-3
Package: com.petertroll.pdfcraftmobile
Minimum Android: 7.0 (API 24)
Target Android: 14 (API 34)

Install
-------
1. Copy the APK to your Android phone.
2. Open it from Files/Downloads.
3. If prompted, allow that file manager to install unknown apps.
4. Tap Install.

Use
---
- Use the Android toolbar's Open command, Android's “Open with”, or PdfCraft's own Open command.
- PdfCraft runs locally/offline inside the app.
- PdfCraft's own file picker supports secondary PDFs/images for combine and insert workflows.
- Use PdfCraft's own Save command after editing. Android will always ask for a destination; it never silently overwrites the source PDF.
- Toolbar Save copy and Share are available after PdfCraft has saved the current changes.
- If the destination picker is canceled, Android cannot write the destination, or the app is recreated, the exact pending bytes remain in private storage. Use Retry/Export recovery in the displayed dialog, or open toolbar overflow > Save recovery later.
- Pending transaction bytes are removed only after a successful destination write. A missing/damaged save transaction is reported instead of silently ignored.

Notes
-----
- This is an unofficial Android wrapper around PdfCraft 0.8.0 with a responsive touch UI adaptation.
- The editor adapts its controls for phones and tablets; landscape can still be useful for complex documents.
- Imported documents and save transfers are limited to 100 MiB.
- No physical Android device or emulator was attached during the server-side build, so the APK has not yet had a hardware tap-through test.
